# Product: SCIMATHIX (SCIMATHNIX)

SCIMATHIX is a learning management system (LMS) focused on Science and Mathematics education. It serves three user roles:

- **Students** — Access lessons, take quizzes, earn XP/achievements, view leaderboards, chat with AI tutoring, and communicate with teachers.
- **Teachers** — Create and manage lessons/quizzes, view analytics on student performance, manage classroom sections, and communicate with students.
- **Admins** — Manage users, academic settings (school years, sections, subjects, levels), view reports, send announcements, and monitor system activity.

Key capabilities:
- Quiz engine with question banks and attempt tracking
- Gamification (XP, achievements, leaderboards)
- AI-powered tutoring assistance
- Real-time chat via Socket.IO
- Announcement and notification system
- PDF lesson uploads with parsing
- Firebase authentication integration
- Activity logging and analytics
